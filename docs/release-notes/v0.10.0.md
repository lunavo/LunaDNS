# LunaDNS 0.10.0 (bản thử)

## Mới

- **Tên miền tuỳ chỉnh**: chọn nhóm tên miền cần đi qua LunaDNS, tự thêm tên miền riêng. Tên miền bạn thêm không bao giờ bị ghi đè.
- **Tự cập nhật danh sách tên miền**: app tải danh sách có ký số từ GitHub mỗi 24 giờ, kiểm chữ ký rồi mới áp. Tải lỗi thì giữ bản cũ. Tắt được bằng công tắc "Tự cập nhật danh sách tên miền".
- **Máy chủ DoH**: thêm Quad9 và AdGuard, ô "Tự nhập" URL DoH, nút **Đo** để chọn máy chủ nhanh nhất.
- **Tách TLS record** (Nâng cao): gửi ClientHello thành hai TLS record, cho mạng lọc SNI kỹ hơn.
- **Tìm cấu hình hợp mạng**: tự thử các tổ hợp điểm cắt, độ trễ và DoH, rồi áp tổ hợp đầu tiên vào được Steam.
- Cửa sổ chính chia thành bốn vùng: Kiểm tra, Trạng thái, Cập nhật, Gỡ & dọn.
- Logo mới. Bản macOS nhỏ hơn.

## Tải

- **LunaDNS-Setup-0.10.0.exe**: khuyên dùng trên Windows.
- **LunaDNS-0.10.0-portable.zip**: giải nén cả thư mục rồi bấm đúp `LunaDNS.exe`.
- **LunaDNS-0.10.0-macos-arm64.dmg** (chip Apple) / **…-macos-x64.dmg** (Intel): bản xem trước.
- Đừng chọn "Source code (zip)": trong đó không có app. Không cần cài .NET.

## Lưu ý

- Bản chưa ký số: Windows hiện "Windows protected your PC" → **More info → Run anyway**. Kiểm file bằng `SHA256SUMS.txt`.
- Windows 11 bật **Smart App Control** sẽ chặn hẳn bản chưa ký.
- Cần quyền Admin.

Hướng dẫn: [Bắt đầu nhanh](https://github.com/lunavo/LunaDNS/blob/main/docs/guide/00-bat-dau-nhanh.md) · [Cài đặt](https://github.com/lunavo/LunaDNS/blob/main/docs/guide/01-cai-dat.md).

## English

**New**

- **Custom domains**: pick which domain groups go through LunaDNS and add your own domains. Domains you add are never overwritten.
- **Domain list auto-update**: the app downloads a signed domain list from GitHub every 24 hours and checks the signature before applying it. If a download fails it keeps the previous list. Turn it off with the "auto-update domain list" switch.
- **DoH servers**: Quad9 and AdGuard added, a custom DoH URL field, and a **Measure** button that picks the fastest server.
- **Split TLS record** (Advanced): sends the ClientHello as two TLS records, for networks with stricter SNI filtering.
- **Find a configuration that works**: tries split point, delay and DoH combinations and applies the first one that reaches Steam.
- The main window is arranged into four zones: Check, Status, Update, Uninstall & clean up.
- New logo. Smaller macOS build.

**Download**

- **LunaDNS-Setup-0.10.0.exe**: recommended on Windows.
- **LunaDNS-0.10.0-portable.zip**: extract the whole folder, then double-click `LunaDNS.exe`.
- **LunaDNS-0.10.0-macos-arm64.dmg** (Apple chip) / **…-macos-x64.dmg** (Intel): preview.
- Do not pick "Source code (zip)": it has no app in it. No .NET install needed.

**Notes**

- Not code-signed: Windows shows "Windows protected your PC" → **More info → Run anyway**. Verify files with `SHA256SUMS.txt`.
- Windows 11 with **Smart App Control** on blocks unsigned builds outright.
- Needs Administrator rights.
