# LunaDNS 0.10.2 (bản thử)

## Sửa lỗi

- Windows: bấm mở LunaDNS ở trang cuối của bộ cài không còn báo lỗi "The requested operation requires elevation" (lỗi 740).
- macOS: **Thoát & khôi phục** vẫn tắt tính năng khi dịch vụ nền vừa trả lời chậm. Nếu dịch vụ nền không trả lời, app báo rõ và chỉ lệnh `sudo lunadns off` thay vì thoát như đã khôi phục xong.
- macOS: khi dịch vụ nền tự tắt một tính năng vì lỗi lặp lại, thẻ tính năng hiện "Đã tự tắt vì lỗi" kèm thông báo, như trên Windows.

## Tải

- **LunaDNS-Setup-0.10.2.exe**: khuyên dùng trên Windows.
- **LunaDNS-0.10.2-portable.zip**: giải nén cả thư mục rồi bấm đúp `LunaDNS.exe`.
- **LunaDNS-0.10.2-macos-arm64.dmg** (chip Apple) / **…-macos-x64.dmg** (Intel): bản xem trước. Sau khi cài, bấm **Cài lại dịch vụ nền** khi app đề nghị.
- Đừng chọn "Source code (zip)": trong đó không có app. Không cần cài .NET.

## Lưu ý

- Bản chưa ký số: Windows hiện "Windows protected your PC" → **More info → Run anyway**. Kiểm file bằng `SHA256SUMS.txt`.
- Windows 11 bật **Smart App Control** sẽ chặn hẳn bản chưa ký.
- Cần quyền Admin.

Hướng dẫn: [Bắt đầu nhanh](https://github.com/lunavo/LunaDNS/blob/main/docs/guide/00-bat-dau-nhanh.md) · [Cài đặt](https://github.com/lunavo/LunaDNS/blob/main/docs/guide/01-cai-dat.md).

## English

**Fixes**

- Windows: launching LunaDNS from the installer's last page no longer fails with "The requested operation requires elevation" (error 740).
- macOS: **Quit & restore** still turns features off when the background service was slow to answer. If the background service does not answer, the app says so and points to `sudo lunadns off` instead of quitting as if everything had been restored.
- macOS: when the background service turns a feature off because it kept failing, the feature card shows "stopped because of an error" with a message, as on Windows.

**Download**

- **LunaDNS-Setup-0.10.2.exe**: recommended on Windows.
- **LunaDNS-0.10.2-portable.zip**: extract the whole folder, then double-click `LunaDNS.exe`.
- **LunaDNS-0.10.2-macos-arm64.dmg** (Apple chip) / **…-macos-x64.dmg** (Intel): preview. After installing, click **Reinstall background service** when the app offers it.
- Do not pick "Source code (zip)": it has no app in it. No .NET install needed.

**Notes**

- Not code-signed: Windows shows "Windows protected your PC" → **More info → Run anyway**. Verify files with `SHA256SUMS.txt`.
- Windows 11 with **Smart App Control** on blocks unsigned builds outright.
- Needs Administrator rights.
