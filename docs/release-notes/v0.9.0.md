# LunaDNS 0.9.0 (bản thử)

Bản phát hành đầu tiên. Giúp vào Steam khi nhà mạng chặn DNS hoặc lọc SNI.

## Tải

- **LunaDNS-Setup-0.9.0.exe** — khuyên dùng. Cài vào Program Files, gỡ qua Settings → Apps.
- **LunaDNS-0.9.0-portable.zip** — giải nén rồi bấm đúp `LunaDNS.exe`. Không có tác vụ dọn dẹp lúc khởi động máy.
- Không cần cài .NET.

## Lưu ý

- Bản chưa ký số: Windows hiện "Windows protected your PC" → **More info → Run anyway**, và UAC ghi "Unknown publisher". Kiểm file bằng `SHA256SUMS.txt` (xem hướng dẫn cài đặt).
- Windows 11 bật **Smart App Control** sẽ chặn hẳn bản chưa ký.
- Cần quyền Admin.

Hướng dẫn: [Bắt đầu nhanh](https://github.com/lunavo/LunaDNS/blob/main/docs/guide/00-bat-dau-nhanh.md) · [Cài đặt](https://github.com/lunavo/LunaDNS/blob/main/docs/guide/01-cai-dat.md).

## English

First release. Gets you into Steam when your ISP poisons DNS or filters SNI.

**Download**

- **LunaDNS-Setup-0.9.0.exe** — recommended. Installs to Program Files, uninstall from Settings → Apps.
- **LunaDNS-0.9.0-portable.zip** — not an installer: extract the whole folder, then double-click `LunaDNS.exe`. No boot-time cleanup task.
- **LunaDNS-0.9.0-macos-arm64.dmg** (Apple chip) / **…-macos-x64.dmg** (Intel) — preview.
- Do not pick "Source code (zip)": it has no app in it. No .NET install needed.

**Notes**

- Not code-signed: Windows shows "Windows protected your PC" → **More info → Run anyway**, and UAC says "Unknown publisher". Verify files with `SHA256SUMS.txt`.
- Windows 11 with **Smart App Control** on blocks unsigned builds outright.
- Needs Administrator rights.
