# LunaDNS 0.10.1 (bản thử)

## Mới

- **Tự bật lại**: app nhớ các tính năng bạn đang bật và tự bật lại khi mở app hoặc khởi động lại máy. Tắt bằng ô "Tự bật lại". Thoát bằng "Thoát & khôi phục" (hoặc Cmd+Q trên macOS) thì app quên trạng thái; đăng xuất hay khởi động lại máy thì vẫn nhớ.
- **DoH dự phòng nhanh hơn**: app hỏi song song các máy chủ DoH và tạm bỏ qua máy chủ chết trong 5 phút, nên máy chủ chính bị chặn không còn làm mỗi lượt tra chậm vài giây. Thẻ Định tuyến DNS cho biết máy chủ đang trả lời, ví dụ "DoH: Google (dự phòng)".
- **Tự dọn thay đổi sót lại**: lúc khởi động, LunaDNS gỡ các thay đổi do chính nó để lại mà journal không còn ghi (file resolver, PAC trên macOS, luật NRPT, dòng hosts trên Windows). Journal hỏng không còn làm app hay dịch vụ nền bị crash.
- **macOS: lý do lỗi rõ hơn**: thẻ tính năng hiện đúng lỗi từ dịch vụ nền thay cho "lỗi không rõ". Chẩn đoán có thêm log của dịch vụ nền.

## Sửa lỗi

- macOS: bấm X rồi bấm icon trên Dock giờ hiện lại cửa sổ.
- macOS: cài dịch vụ nền không còn treo 15 giây rồi báo lỗi "launchctl bootstrap" dù đã cài xong.
- macOS: khi một tài khoản khác đang dùng máy (Fast User Switching), app báo rõ thay vì đề nghị cài lại dịch vụ nền, việc vốn sẽ tắt định tuyến của người kia.
- Kết nối tới địa chỉ IP bị chặn ngầm chuyển sang địa chỉ kế tiếp sau 1 giây thay vì chờ hết 5 giây.

## Tải

- **LunaDNS-Setup-0.10.1.exe**: khuyên dùng trên Windows.
- **LunaDNS-0.10.1-portable.zip**: giải nén cả thư mục rồi bấm đúp `LunaDNS.exe`.
- **LunaDNS-0.10.1-macos-arm64.dmg** (chip Apple) / **…-macos-x64.dmg** (Intel): bản xem trước. Sau khi cài, bấm **Cài lại dịch vụ nền** khi app đề nghị.
- Đừng chọn "Source code (zip)": trong đó không có app. Không cần cài .NET.

## Lưu ý

- Bản chưa ký số: Windows hiện "Windows protected your PC" → **More info → Run anyway**. Kiểm file bằng `SHA256SUMS.txt`.
- Windows 11 bật **Smart App Control** sẽ chặn hẳn bản chưa ký.
- Cần quyền Admin.

## English

**New**

- **Turn back on**: the app remembers which features you had on and turns them back on when the app opens or the computer restarts. Turn it off with the "Turn back on" box. Quitting with "Quit & restore" (or Cmd+Q on macOS) forgets the state; logging out or restarting keeps it.
- **Faster DoH fallback**: the app queries DoH servers in parallel and skips a dead server for 5 minutes, so a blocked primary no longer adds seconds to every lookup. The DNS routing card shows which server is answering, e.g. "DoH: Google (fallback)".
- **Cleans up leftovers**: at startup LunaDNS removes changes it made that the journal no longer records (resolver files, the macOS PAC, NRPT rules, hosts lines on Windows). A corrupt journal no longer crashes the app or the background service.
- **macOS: clearer error reasons**: feature cards show the background service's actual error instead of "unknown error". Diagnostics now includes the background service's log.

**Fixes**

- macOS: clicking the Dock icon after closing the window with X shows the window again.
- macOS: installing the background service no longer hangs for 15 seconds and reports a "launchctl bootstrap" error even though it installed.
- macOS: when another account is using the Mac (Fast User Switching), the app says so instead of offering to reinstall the background service, which would turn off the other person's routing.
- Connections to a silently blocked IP move on to the next address after 1 second instead of waiting the full 5 seconds.

**Download**

- **LunaDNS-Setup-0.10.1.exe**: recommended on Windows.
- **LunaDNS-0.10.1-portable.zip**: extract the whole folder, then double-click `LunaDNS.exe`.
- **LunaDNS-0.10.1-macos-arm64.dmg** (Apple chip) / **…-macos-x64.dmg** (Intel): preview. After installing, click **Reinstall background service** when the app offers it.
- Do not pick "Source code (zip)": it has no app in it. No .NET install needed.

**Notes**

- Not code-signed: Windows shows "Windows protected your PC" → **More info → Run anyway**. Verify files with `SHA256SUMS.txt`.
- Windows 11 with **Smart App Control** on blocks unsigned builds outright.
- Needs Administrator rights.
